  • 절차 홈페이지 내 게시글 크롤링 → 데이터 정제 → 키워드 추출 → 워드클라우드 및 공출현네트워크 제작
  • 온라인 커뮤니티 분석에 대한 결과를 확인할 수 없어 담당자의 경험과 직관으로 커뮤니티를 분석

  • 프로그래밍에 익숙하지 않은 직원의 경우 프로그램 실행에 어려움 존재

  • Okt에 매칭되지 않는 신조어, 인터넷 용어, 초성 단어도 추출될 수 있도록 코드 수정
  • 프로그램 실행 UI를 별도로 제작해 사용 편리성 증대
  • 담당자 직관에 의존하던 이전 방식에서 키워드 분석을 통해 데이터로 사이트 특성을 파악 할 수 있음
  • 별도 다수의 프로그램을 구동할 필요 없이, 실행 한 번으로 키워드 분석 결과를 확인
  • 온라인 커뮤니티 분석에 대한 책자 제작에 활용

리뉴얼 홈페이지 기획 및 업체 소통

  • 문제 어두운 색상, 올드한 디자인으로 사용 접근성 떨어짐
  • 관리자 페이지가 있으나 사이트 관리 기능이 사용자 페이지에 부착되어있어 관리자 페이지 실 사용률 떨어짐
  • 접속자 수 외 시민제보 건수를 파악할 수 있는 통계 부재
  • 이전 홈페이지에 대한 만족도 조사 시행 → 홈페이지 기획 시 이용자 피드백 반영 : 시민에게 친근한 디자인 기획, 실적 부분을 통해 기관의 활동 가시화, 관련 자료 확인 페이지 추가 개설
  • 시민제보 과정을 간편화 : 기존 5개 게시판을 2개로 통합 축소, 메인화면에서 바로 시민제보 가능하도록 위치 재구성
  • 사용자 페이지 접속 없이 관리자 페이지에서 게시글 확인 및 답변 등 관리가 가능하도록 수정
  • 통계 항목 설정
  • GA 분석을 통계에 도입하여 기입식 답변으로는 파악할 수 없는 사용자의 행동 패턴을 분석
  • 접속자 수 변화
  • 시민제보양 변화
